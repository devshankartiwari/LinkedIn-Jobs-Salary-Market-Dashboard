# 💼 LinkedIn Jobs — Salary & Market Dashboard

## 📊 Overview
This project is an exploratory data analysis (EDA) and data visualization dashboard built in Python. It analyzes LinkedIn job postings across three major regions: the **USA, Canada, and Africa**. The notebook cleans messy job data, extracts actionable salary numbers, and visualizes market trends such as top hiring companies, remote work distributions, and salary heatmaps based on seniority.

## ✨ Key Features & Insights
* **Smart Salary Extraction:** Uses Regular Expressions (RegEx) to clean messy string formats (e.g., `$X,XXX.XX \r\n - \r\n $Y,YYY.YY`) into usable numeric minimum, maximum, and average salaries.
* **Regional Comparisons:** Analyzes job availability and average annual salaries across the USA, Canada, and Africa.
* **Seniority & Work Type Analysis:** Categorizes roles (Junior vs. Senior) and compares compensation between On-site, Remote, and Hybrid setups.
* **Market Trends:** Identifies top hiring companies, best locations for tech jobs, and the most active days of the week for job postings.
* **Interactive Visualizations:** Includes histograms, boxplots, and heatmaps using Seaborn and Matplotlib.

## 🛠️ Tech Stack
* **Python 3**
* **Pandas & NumPy:** Data cleaning, transformation, and feature engineering.
* **Matplotlib & Seaborn:** Data visualization.
* **Regular Expressions (re) & AST:** Parsing complex dictionary strings and extracting precise monetary values
